## Project Description

Online retailers lose significant revenue when customers silently stop purchasing
(churn). This project analyzes an e-commerce customer dataset to understand **why**
customers churn and builds a machine learning model that **predicts which customers
are at risk of churning**, so the business can intervene early with targeted retention
offers.

The project covers the full data analytics + AI pipeline:
- Data cleaning (missing values, duplicates)
- Exploratory Data Analysis (EDA) with visualizations
- Feature engineering & preprocessing (encoding, scaling)
- Training and comparing 3 ML classification models (Logistic Regression, Decision
  Tree, Random Forest)
- Model evaluation (Accuracy, Precision, Recall, F1-score, ROC-AUC, Confusion Matrix)
- Hyperparameter tuning (GridSearchCV)
- Feature importance analysis (explainability)
- Business recommendations based on findings

## Dataset

- **File:** `data/ecommerce_customer_churn.csv`
- **Type:** Synthetically generated, realistic e-commerce customer dataset (5,000+
  records, 21 features), created for this project using `generate_dataset.py` (included)
  since no single public dataset matched this program's exact scope. The generation
  logic encodes realistic real-world churn drivers (complaints, satisfaction,
  engagement, recency) so the data behaves like genuine e-commerce behavioral data.
- **Target variable:** `Churn` (1 = customer churned, 0 = customer retained)

### Data Dictionary

| Column | Description |
|---|---|
| CustomerID | Unique customer identifier |
| Gender | Male / Female |
| Age | Customer age (years) |
| MaritalStatus | Single / Married / Divorced |
| CityTier | 1 (metro), 2 (mid-size city), 3 (small town) |
| TenureMonths | Months since the customer joined |
| PreferredLoginDevice | Mobile Phone / Computer |
| PreferredPaymentMode | Credit Card / Debit Card / UPI / COD / E-wallet |
| PreferredOrderCategory | Most-ordered product category |
| SatisfactionScore | Self-reported satisfaction, 1 (low) – 5 (high) |
| NumberOfDevicesRegistered | Number of devices linked to the account |
| NumberOfAddresses | Number of saved delivery addresses |
| ComplainRaised | 1 if the customer raised a complaint recently, else 0 |
| HoursSpentOnApp | Average hours spent on the app/site per week |
| NumOrdersLastMonth | Number of orders placed in the last month |
| DaysSinceLastOrder | Days since the customer's last order |
| AvgCashbackINR | Average cashback received (INR) |
| OrderAmountHikeFromLastYearPct | % increase in order value vs. last year |
| CouponsUsedLastMonth | Number of coupons used last month |
| DistanceFromWarehouseKM | Distance from nearest warehouse (km) |
| **Churn** | **Target: 1 = churned, 0 = retained** |

## Setup / Run Instructions

1. **Clone / download** this project folder.
2. **Create a virtual environment (recommended):**
   ```bash
   python -m venv venv
   source venv/bin/activate      # Windows: venv\Scripts\activate
   ```
3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```
4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
5. Open `CustomerChurnPrediction.ipynb` and run all cells
   (`Kernel → Restart & Run All`). Ensure the `data/` folder (containing the CSV) and
   an `outputs/` folder are present alongside the notebook — the notebook reads the
   dataset from `data/` and saves chart images to `outputs/`.
